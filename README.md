# Fedora Home Lab - BTS SIO SISR

Projet personnel réalisé dans le cadre de ma reconversion vers l'informatique.

Objectifs :

- Administration Linux
- Réseau
- DNS
- SSH
- Firewall
- Monitoring
- Virtualisation
- Documentation technique

Le but de ce projet est de construire une petite infrastructure réseau sous Fedora et de documenter chaque étape.

## État actuel du projet

### Fonctionnel

- Réseau Host-Only VirtualBox
- Adressage IP statique
- Communication entre les VM
- Administration à distance

### En cours

- Mise en place du serveur DNS
- Mise en place du monitoring
